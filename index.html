Getting started

Install it.
Open a song.

Start with the example song or make your own. Cadence saves while you write. You can replay the in-app tour from Settings.

Online backup is optional. You do not need a Google account to use the writing tools.

Where does my writing live?

Cadence keeps your writing and version histories in a local database. Export Markdown to use your writing in another app. On desktop, the Markdown/Git folder holds readable files for this same vault.

On Android, Cadence keeps a local vault in app storage. Export a backup or connect Drive before uninstalling; uninstalling can remove that local copy.

How do I connect Google Drive in 1.7?
  1. Open Settings, then Sync.
  2. Choose Google Drive and Continue with Google. Use the same Google account on each device.
  3. Follow the setup review if Drive already contains a vault. Check the proposed changes before applying them.
  4. Choose your backup pace. Use Download changes when you want to review changes from the other device.

GitHub backup remains desktop-only. Drive requires an internet connection; writing and local rhyme tools work offline.

What if I edit the same song on both devices?

Cadence asks you to review conflicting changes. Check both versions and choose which to keep, or keep both where that option is available. A protected local backup is made before applying the reviewed resolution.

If you edit again while reviewing, Cadence may ask for a fresh comparison. That prevents an older review from replacing newer writing.

How do I install or update on Android?

The Android download is a production-signed APK. Download it from this release site, then allow installation from the browser or file manager you used if Android asks.

For later updates, install the APK over the existing app. Do not uninstall first. Older debug or engineering previews may use a different signing key; export a backup and verify your current writing on another device before replacing one. Uninstalling can remove local writing and device-local history; Drive does not include that history.

Cadence is not on Google Play yet.

Why might Windows show an unknown-publisher warning?

Cadence does not currently have a Windows Authenticode certificate. Its updater signatures and published SHA-256 checksums serve different purposes and do not remove that warning.

Use the official release linked below. If the source or checksum does not match, stop before installing.

Is there a subscription or AI writing?

No. Cadence finds and colors rhymes; it will not write or review a song for you. There is no subscription or paid feature tier.
