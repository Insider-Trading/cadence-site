# Cadence product site

This public repository contains the static product site and public release assets for Cadence.

The application source remains in a separate private repository. Changes pushed to main deploy through GitHub Pages.

The 1.9.0 site draft updates the release label and download links. The getting-started guide covers Overview, Syllables and the metronome. Merge only after the owner approves publication and the public 1.9.0 assets have been independently verified. Keep the PR in draft until the release is public and HEAD requests succeed for its 1.9.0 download and release links.

Run the content and contrast checks with `node --test tests/*.test.mjs`.
