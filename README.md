# Cadence product site

This public repository contains the static product site and public release assets for Cadence.

The application source remains in a separate private repository. Changes pushed to main deploy through GitHub Pages.

The 1.8.0 preparation branch updates downloads and introduces guided Notes and theme previews with real app captures. See docs/SITE_1_8_DESIGN.md for the motion direction and remaining publication checks. Merge only after the owner approves publication and the public 1.8.0 assets have been independently verified.

Run the content and asset checks with node --test tests/site.test.mjs.
